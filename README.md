## Build process

Built with React, TypeScript and [Vite](https://vite.dev).

- Clone or download the repo
- `npm install`
- `npm run dev` to run the application with the Vite dev server on `localhost:4200`
- `npm run build` to type-check and kick off a fresh production build into the output directory (`dist/`)
- `npm run preview` to serve the production build locally

Note: The service worker (generated by [vite-plugin-pwa](https://vite-pwa-org.netlify.app/)) is only produced by the production build. To test service worker changes run `npm run build` followed by `npm run preview`.

### Tests

- `npm test` runs the unit tests with [Vitest](https://vitest.dev) and Testing Library
- `npm run e2e` runs the end-to-end tests with [Playwright](https://playwright.dev) (run `npx playwright install chromium` once beforehand)
- `npm run lint` / `npm run typecheck` / `npm run format:check`
